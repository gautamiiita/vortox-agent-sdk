Widget harness

A stand-in host page for exercising the chat widget — page context, DOM actions, downloads — without a host application.

Development only. This page talks straight to the sidecar, which a real host must never do — a host serves the widget itself and relays chat through its own endpoint, so the browser never reaches the sidecar and never holds a key. That protection is absent here; the loopback port binding is what stands in for it. Do not serve this page from a sidecar reachable beyond localhost.

The mutation log is the check that matters: if the widget reports “applied” for something the log never saw, or the log shows a change to an out-of-scope element, that is a real defect.
